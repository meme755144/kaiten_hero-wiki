### 森～水
{: .mb-5 }

- **基礎装備と操作**
  - タウン右下から箱を開けてコラボ武器を拾う。
  - ATKが一番高いムノウバーベルと、リーチの長い竹槍を装備しておけば多少は楽になる。
  - 敵の周りをぐるぐる回れば水ボスまで行ける。
  - ※死にそうなら街に戻るを押せるよう準備しておく。
- **任意：今後の攻略を楽にする厳選**
  - もしやる気があるならここで落ちるアクセに次元オーブを使い改造スクロールに交換し、ドロップ増加Lv2以上がつくまで（リセマラ）厳選しよう。
  - 今後の攻略がとても楽になる。
{: .mb-5 }

### 空
{: .mb-5 }

- **生存戦略とステータス準備**
  - 敵が一気に強くなるので木の短剣を複数並べ、武器強化から吸血スキルをとる。
  - 猛撃の欠片と鉄壁の欠片は1000個は最低限いる（空5まで）。
  - デイリー報酬からもらうSPで浄化して集めよう。
  - 不足している場合は、「森？」への再挑戦あるいは放置で集めよう。
- **空9突破のための準備**
  - 空5から落ちるエンチャで火属性と、強いまたは硬いをつけるとよい。
  - 空9までは倉庫2000で行ける。
{: .mb-5 }

### 火山
{: .mb-5 }

- **火山進入～火山5までの準備**
  - 敵が強すぎて猛撃・鉄壁オーブが500ぐらいは欲しいので、魔の島で周回する
  - 死にたくないのでオーブ1000貯めてから進んでいい
- **火山5での職業開放と育成アドバイス**
  - 火山5まで行くと職業が開放される
  - 次元オーブ→魂の箱→職業キーと交換することで短剣の職業、盗賊の各Lvを上げれる
  - 類友はまだ弱いので他を上げるとよい
- **火山9突破と、猛撃・鉄壁オーブ大量獲得のための放置**
  - 火山9までひたすら魔の島でオーブを拾って800～1000ぐらいになれば火山9を攻略
  - あとはスキルや硬いなどでDEFを上げて放置できるようになるまで頑張ると猛撃・鉄壁オーブが山のように拾える
  - 魂憑依に勇者の魂が追加され、これが強いのでつけておこう
{: .mb-5 }

### 沼
{: .mb-5 }

- **沼進入～沼5：斧ビルドへの移行と準備**
  - 火山9で放置し上限までいけば沼5までは到達可能
  - ここで斧にビルドを変更、ミスリル斧を並べ+10に強化する
  - 斧欠片を火山7か浄化で集め、浄化の書を集めに森H5に行く
  - ついでに討伐数も稼ぎ魔法弾を使えるようにする
  - 斧は最初は弱いが魔法弾が鬼つよなので、放置は短剣、手動攻略は斧でいく
- **沼9突破のための手動攻略と詰まった時の対策**
  - 魔法弾ならミスリル斧☆1で沼9までごり押し可能（頑張って敵の攻撃はよける）
  - 手動がつらい場合は斧欠片集め、魔法弾強化（要SP）、またはミスリル斧の浄化＋浄化の書集めをする
{: .mb-5 }

### 深海
{: .mb-5 }

- **深海進入～深海3までの資源集め**
  - 浄化の書を森H5や水H5、水デイリーなどで1～2万集める
  - 沼2で魂の箱を集め、BHダガーを浄化する
  - 十分強化したBHダガー（☆2～30）があれば深海3まではいけるはず
  - 足りない場合は武器欠片や浄化の書集め、浄化して☆上げよう
  - 銀の卵が手に入ったらペットを強化し配置しておこう
  - ペットの金箱から焔斧を拾えたらそれを1本だけ特化し浄化する
  - 深海3で武器欠片Ⅱを集め、3に交換する
- **中盤～終盤の基本構成とスキル使い分け**
  - ここからの構成はBHダガー6＋焔斧1＋翡翠（浄化OPつき）を基本とし、放置は盗賊、ボス攻略は魔法士と使い分ける
  - 短剣には動きそうなと幸運なをつけ、斧には同期するをつける
  - （今後の付け替えが手間だが水属性の相手なら土属性をつけるとなおよい）
- **効率的な周回ルーティン**
  - 魂の箱集めに沼N2、武器欠片集めに深海3、ついでに金策もする
  - 旋撃の欠片を購入しよう
- **火山H4での厳選とラスボスへの準備**
  - ある程度伸撃と火力があれば火山H4で壊れた改造スクロールを集められる
  - ここで改造スクロールを使いガチャをするのもよいが、先にアクセ成長をしてから使ったほうがOPのLvが高いアクセができる
  - 枯命の三葉や、疾風の羽布を6Lvぐらいまで強化しスクロールを使おう
  - ラスボス用に風のアクセに戦闘用OPもつけたい
  - ※沼Hにはいかないこと（死んでもいいなら別）
{: .mb-5 }

### 果ての空
{: .mb-5 }

- **果ての空安定攻略のためのステータス目標**
  - 旋撃の欠片をため、BHダガーのSPDが4600（3ヒット）。
  - ☆50ぐらいになれば、果ての空安定も見える。
  - 浄化の書を3万まで、集めに行ってもよい。
- **倉庫拡張チャレンジとボス攻略**
  - 倉庫上限がおいしいので、チャレンジしよう。
  - 倉庫の欠片から倉庫のオーブ3が交換できるが、手間だし、そこまで大きな影響はないのでしなくていい。
  - ボスは気合でよけるか、火力十分なら魔法士で魔法弾打ったほうが安定。
{: .mb-5 }

### ???の地
{: .mb-5 }

- **???の地の推奨構成とステータス目標**
  - 【推奨構成】
  - ☆80～100BHダガー・翡翠、焔斧（弾消し）。
  - 短剣：動きそうな2、幸運な（短剣1本に風のようなⅧをつける）。
  - 斧：属性2、同期する、節制する（凸上げてないなら節制→幸運でもよいが、CRI.R十分ならいらない）。

  - ボスまで行けば、後はダイヤ型に移動すれば被弾はしない（ボスとの位置関係には注意）。

### 第一部クリア
{: .mb-5 }

- **流転解禁と第2部開放の条件**
  - 【第一部クリア】
  - 流転が解禁される。
  - 1から始まることになるが、ノーデスクリアができていれば2部が開放、死んでしまった場合は、そのステージの進捗の確率で2部が開放される。
  - 二次元オーブで死亡回数を減らせるアイテムが交換できるので、もし課金に躊躇いがない場合は、これで死亡回数を0にしたい。
- **初回流転時の引き継ぎおすすめ戦略**
  - 初回流転は、武器引き継ぎに浄化翡翠を設定するのがおすすめ。
  - アクセも引き継げるようにして、ドロ増をいれるのがよいだろう。
  - 余ったら、☆増加もあるとよい。

### 剣士の街
{: .mb-5 }

- **剣士の街の難易度と今後の育成方針**
  - 【剣士の街】
  - 敵が若干強くなるが、浄化の暴力でも十分対処可能。
  - しかし、今後のことも考えると、以下の2パターンを試したほうがいい。
- **おすすめの強力ビルド2パターン**
  - **パターン1：貫通100%ビルド（防御無視1000倍ダメ）**
    - アクセにピアシングLv40(40%)、貫通Ⅷで残留込み20%、ピアシング強化で8Lv(40%)。
    - 貫通が合計100%となり、敵の防御無視で1000倍ぐらいのダメージが入る。
  - **パターン2：魔法弾CD45ビルド（無CD連打）**
    - 魔法弾CD45。
    - 魔法弾を連打すると、貫通100%の1000倍という、とんでも倍率よりさらに強い不思議。
- **両ビルドのコスト・メリット比較**
  - どちらもスクロール消費が重たいが、魔法弾のほうが消費が激しい。
  - 貫通100%でも十分火力が出るので、やる価値はある。
  - ただし、魔法弾の場合はかなり強い上にCDがないので、いつでも自由に素材を集められるメリットがある。
{: .mb-5 }

### 大釜
{: .mb-5 }

- **大釜の推奨構成とエンチャント詳細**
  - 【推奨構成】
  - 翡翠4・焔斧1・脆弱・減速・斥力（反発2）。
  - 翡翠エンチャ：動きそうな2 or 貫通（ピアシングなら）・挑発（大釜では不要だが、積みたい青エンチャもないので）。
  - 斧エンチャ：属性2・調和共振（ピアシングなら赤不要、貫通100行けないので火力にならない）。
- **大釜の解禁と資源逆転現象（箱の大量獲得）**
  - ランサーの聖地を突破すると解禁。
  - 大量の箱が手に入り、「今までの浄化は何だったんだ…」レベルで浄化が進む。
  - 今度は、SPが圧倒的に足りなくなる逆転現象が起きる。
  - 今後の短剣はすべて翡翠に切り替えるが、流転で引継げる武器だけを強化する。
- **Wave200以降のギミック対策とドロップ狙い**
  - Wave200からは、敵が弾を飛ばしてくる。
  - 定撃の欠片や定命の欠片を落としておいしいので、できる限り倒したい。
  - 瞬殺できない場合は、減速や反発オーラで時間稼ぎをしつつ、魔法弾またはピアシングで貫通100%をして倒すことになる。
- **おすすめの流転タイミング**
  - 浄化を無理のない範囲で上げたら、流転してもいい。
  - 流転スキル（特に引継ぎ数やドロップ抽選）がほしい。
{: .mb-5 }
