## まずはじめに

### 序盤のゲームの進め方
{: .mb-5 }

- Lvアップや転生時に獲得する**スキルポイント**を使いスキルを強化、または武器を強化するとステータスが強化される。

- **欠片の収集**<br>
  **猛撃の欠片**や**鉄壁の欠片**などを集めると、その所持数に応じてステータスが強化される。

- **上限の拡張**<br>
  **倉庫の欠片**や**倉庫のオーブ**などを集めると所持上限が増える。

基本的には、これらを繰り返していくとよいでしょう。
{: .mb-5 }

### どの武器が強い？
{: .mb-5 }

- どの武器もある程度使えますが、最初は短剣をとりあえず並べておくといいでしょう。

- 短剣は武器強化によって吸血というダメージを与えると回復する効果があり、なんと最大強化で50も回復します。

- 敵が複数いるとその分回復するため、耐久力が大幅に向上します。

{: .mb-5 }

### 武器の強化方法は？
{: .mb-5 }

- **水の荒野5をクリア**すると「魂武器」といった強化が出来るようになります。

- 右上の**天使に話しかける**と、スキルポイントを使うことで武器を強化（魂注入）できます。

- 武器を強化することで**ATK、SPD（回転速度）などが上昇**し、敵を倒す効率が上昇します。

- 使う武器はスキルポイントに余裕があれば強化していきましょう。
{: .mb-5 }

### 武器の浄化ってなに？
{: .mb-5 }

- 武器を**+2以上に上げていく**と浄化することができるようになります。

- 武器を浄化すると**猛撃の欠片や猛撃の欠片（武器種）、魂の箱**が手に入ります。

- 序盤はスキルポイントに余裕があまりないため、**効率のいい+6の浄化**をすることをお勧めします。
{: .mb-5 }

### +10強化したらSPDがばらける
{: .mb-5 }

- 短剣などの武器を**+10にするとSPDもランダムに変化**します。

- SPDがばらけると回転にムラが出来て敵が接触しやすくなったり、飛剣がいい感じに飛ばなくなって困ります。

- これを防ぐために序盤は**+9で止めたり、+10のSPD最大値を狙う**ことが多いです。

- SPDを最大値にするには**魂再注入で自動注入のチェックを外して**おき、SPD最大値にしたい武器を選び、自動再注入を押します。

- もしATKやCRI.Cなどが最大値になっている場合は、**1度再注入ボタン**を押しましょう。

- 警告が出てきてもはいを押すと、**もう一度自動再注入ができる**ようになります。

- 再注入には**魂の箱が必要**なので、序盤で魂の箱が足りない場合は次元オーブを1個で魂の箱を5000個交換できるのでしましょう。
{: .mb-5 }

### 〇〇ステージに勝てない
{: .mb-5 }

- 基本はそれまでに手に入る**ステータスが上がるアイテムを集めていけば**いつか攻略できます。

- まだ**上限まで持っていないアイテム**を集めていくといいでしょう。

- もっと早く攻略したい人は、**武器を強化し、武器スキルを整え、敵の行動パターン**をよく見てみましょう。

- 特に**空の島・伍の島**のボスから落ちる**「強い」と「硬い」のエンチャントは強い**です。

- 攻撃力が上がると放置の効率も上がるためなるべく**高Lvのエンチャント**を付けていきましょう。
{: .mb-5 }

### エンチャントって何？どうやってつけるの？
{: .mb-5 }

- 武器本体のみ効果がある**赤いエンチャント**と、全体的に効果があることが多い**青いエンチャント**があります。

- エンチャントは武器を強化し**+1以上になった武器**に付けることができます。

- 右側のエンチャント屋に武器が並んでいない場合は**武器フィルターの確認**、またはエンチャントを付けたい**武器の強化**をしてみましょう。
{: .mb-5 }

### 効率のいいエンチャントの付け方
{: .mb-5 }

- エンチャントは**Lvが1つ上がるごとに成功率が10%落ちます**。

- 例えば、エンチャントを付けていない武器に「強いⅠ」のエンチャントを付けると、**成功率は80%**。
  - 「強いⅠ」がついている武器に「強いⅠ」を付けると**90%**。
  - 「強いⅠ」がついている武器に「強いⅢ」を付けると**70%の成功率**となります。
  - 逆に「強いⅢ」から「強いⅡ」に下げると**100%成功**します。

- 1つずつLvを上げていくと1から10までに80%の挑戦を10回しないいけなくなり（ $$ 0.8^{10} \approx 0.107 $$ ）、あまり効率がよくありません。

- **1つ飛ばしか、2つ飛ばし**の方が効率が良くなります。

- **例**
  - 2Lvずつ上げる： $$ 0.7^5 = 16.807\% $$
  - 2Lvずつを2回、3Lvずつを2回： $$ 0.7^2 \times 0.6^2 = 17.64\% $$
  - 3Lvずつ上げ、最後に1Lvあげる： $$ 0.6^3 \times 0.8 = 17.28\% $$

- エンチャントは**高レベルのエンチャントが貴重**であることが多いので、多く余っているエンチャントを使いつつも、**ⅨからⅩに上げるようにする**とよいでしょう。
{: .mb-5 }

### エンチャントの残留とは？
{: .mb-5 }

- エンチャントをしたときに**10%～100%残留しました**と表示されます。

- これは**上書きする前のエンチャントがその%分だけ効果を発揮**している状態です。

- **【例えば】**
  - 「強いⅩ」のエンチャントから更に「強いⅩ」のエンチャントを重ねると、「強いⅩ」のエンチャントが**10～100%残留**します。
  - 更にエンチャントが成功すると100%あるので**効果量は110～200%**になります。

- 残留は**別のエンチャントでも可能**です。
  - 強いⅩから同期Ⅸにエンチャントすると**強いⅩの残留%分と同期Ⅸ**が乗ります。

- 今何%発揮されているのか調べるには、武器画面の調べたい**武器アイコンのイラスト部分をタップ**すると詳細画面が出てくるのでそこで分かります。
{: .mb-5 }

## ステージ毎攻略

### 初めての森
{: .mb-5 }

- 武器を並べて走るだけで突破可能。

- 回転する武器を敵にかするように動くと安全。

- 初めにデイリー報酬のスキルポイントを受け取っておくとより楽に攻略できる。
{: .mb-5 }

### 水の荒野
{: .mb-5 }

- 同じく走るだけで突破可能。

- 敵が少し硬いので「猛撃の欠片」や「鉄壁の欠片」を集めたい。

- 森5のボスを倒した後放置することで集まる。

- 攻撃や防御が1個に付き1%伸びるため数がそろうと強さを実感する。

- ついでに落ちる素材で武器強化スキルの解放・強化を行おう。

- スキルポイントを稼ぎたい場合は水1（手動周回）→ハード森1→4と集めていくとよい。
{: .mb-5 }

### 空の島 1F～5F
{: .mb-5 }

- 敵がそこそこ強くなっていくので水の荒野で「倉庫の欠片I」を集めつつ、「猛撃の欠片」と「鉄壁の欠片」を現在の所持上限まで集めていきたい。

- 5Fのボスは突進を2回してくるが、突進前に敵の周りを回転しておき、1回目を躱した後そのまま直進するようにすれば追いつかれない。
{: .mb-5 }

### 空の島 6F～9F
{: .mb-5 }

- 遠距離攻撃が追加され一段と難易度が増加。

- 5Fの島のボスからエンチャントが落ちるので、「強打する」または「焔輝放つ」（属性は残留の場合は100%じゃないと効果がない）と「強い」または「硬い」を装備中の武器につけよう。

- 敵の弾を避けるように敵の集団を回転しつつ攻撃するか、始めに動いて弾の同時着弾をずらし、防御力と短剣の回復力で耐え抜くか等の戦法がある。

- 9Fのボスは弾をはじめに8方向ばらけさせた後、自機狙いのように放ってくる。

- 8方向は縦横斜めと固定なため、うまくすり抜けるようにすればギリギリまで近づいていてもいいが危険なためタイミングを見計らって離れよう。

- ボスが弾を撃ちそうになったタイミングで近づきすぎないようにしつつ、弾を構えたら少し離れて横に移動していればノーダメージも可能。
{: .mb-5 }

### 火山 1F～5F
{: .mb-5 }

- 炎攻撃が追加され、炎に触れていると多段ヒットする上に火力が高い。

- 空の島攻略で棍棒と斧は魔法攻撃が消せるようになったが、この炎は消せないので諦めて避けよう。

- 火山の攻略にはオーブの数が重要なので、まずは下記の通り集めよう。
  - 空の島 9F：「倉庫の欠片Ⅱ」
  - チャレンジ 湿原？or魔の島：「猛撃のオーブ」、「鉄壁のオーブ」

- 300個ぐらいあれば火山5まで攻略は可能。

- 5Fボスは大量の炎をかなりの速度で打ち出してくる。

- 炎にかすることを前提として耐久力を高めておこう。

- 「風のような」のエンチャントを付けて走ると避けやすくなる。
{: .mb-5 }

### 火山 6F～9F
{: .mb-5 }

- オーブが600個ぐらいになると火山9Fの攻略が可能。

- 火山9Fの放置目安としてオーブ800個程は集めておき、少し耐えれるようになったら死に戻りで集めるといい。

- 火山5Fをクリアした事によって「職業屋」が解放されており、使っている武器の職業に切り替え、スキルを強化するとその職業の武器を並べた方が強くなる。

- 次元オーブで魂の箱を交換し、魂の箱を職業キーに交換することで、現時点では難易度が高い無限ステージを攻略して得るはずの職業キーを簡単に入手することができるのでやっておこう。

- 火山9Fボスはレーザーを薙ぎ払う形で撃ってくる。

- 反時計回りに回転していたら喰らわないので、ノーダメージで攻略可能。
{: .mb-5 }

### 沼 1F～5F
{: .mb-5 }

- 時間経過でダメージを受けるマップだが、吸血があるので問題はない。

- 敵が爆撃のような攻撃を足元に撃ってくるため、放置して立っていたら当たってしまう。

- 即死級なので赤い予兆が現れたら素直に避けよう。

- 敵に接触しても大してダメージを受けないので囲まれても安心して敵を押し出してよい。

- なお、爆撃はエフェクトが終わるまで当たり判定が少し残っているので、予兆を回避するのに慣れてる人もきちんと待つように。

- 5Fボスは大量 of 爆撃をランダムな位置＋足元にばらまいてくる。

- 時間をかければ突破は可能。
{: .mb-5 }

### 沼 6F～9F
{: .mb-5 }

- 沼5Fをようやくクリアできる程度での戦力では困難なので、各オーブカンストを目指そう。
  - 火山9F or デイリー 空の島 ボス：「倉庫のオーブⅠ」
  - 初めての森5F（Hard）or デイリー 森の主 （Hard）：浄化の書

- 攻撃パターンは沼5Fまでとほぼ同じだが、2段突進や弾を撃つ敵が追加されている。

- 沼6Fから落ちる「幸運な」のエンチャントが特に優秀なので複数付けて会心率を上げるとよい。

- 沼9Fボスは会心抵抗があり硬い。

- 倍速だと回避がやや難しい縦の縞模様と横の縞模様の絨毯爆撃が交互に飛んでくる。

- 素直に等倍で避けていくか、火力十分で倍速で挑む場合は敵を斜めに押し出しながら動くと遅くなるので調整がしやすい。
{: .mb-5 }

### 深海 1F～5F
{: .mb-5 }

- まずは魔法士クラスに切り替え魔法弾で敵を数体倒し、銀の卵を入手したい。

- 魔の島や森H5を周回し転生することでSPを稼ぎ、魔法弾のダメージを1Lvにすると倒せる可能性が見えてくる。

- その後しばらくは浄化の書を集めつつBHダガーの浄化をして☆を上げていこう。

- 沼2Fで魂の箱を集め、森H5を周回し浄化の書を10,000個まで集めたい。

- 沼2Fで稼いだお金を使ってデイリーチケットを購入し森Hデイリーを回るか、森H5周回を旋撃の欠片を買うかは好み。

- 強化が進んだら無限ステージのWaveも進んでいくため☆上げが捗っていく。

- 無限ステージを短剣メインで攻略する場合には、同期エンチャントを付与した斧を1つつけると弾消しができるので、火山5Fボスから炎を撃たれて死ぬことはなくなる。

- 浄化の書10,000、短剣の☆平均20、職業スキル上げを行ったら攻略することができるようになる。

- まずは深海3Fで猛撃の欠片Ⅱ：短剣、斧を入手し、上限まで貯めよう。

- 放置後の敵が若干強いので再挑戦するのもよい。

- その後欠片ⅡをⅢに変換して再度欠片Ⅱを集めるとよい。

- 交換しすぎて効率よく倒せなくならないように注意しよう。

- ボスの突破だけなら魔法弾の方が早いのでこの後に斧を強化してもよい。

- ☆は10～20ぐらいで十分だろう。

- アクセサリーと「風のような」エンチャントを付け移動速度を2.3まで上げたらボスの突進は避けれるようになる。

- 突進が来る間に離れ、突進する直前に横に避けると安定する。

- 実は深海3Fや深海5Fはお金がかなりおいしい。

- コレクターのお金Lvを強化することで最大32倍増えるようになるため、無職で攻略出来れば旋撃・伸撃の欠片を大量に購入することができる。

- 旋撃を集め、BHダガーが2ヒット（SPD2.3K以上）になると、一気に行ける範囲が広がるので、武器欠片Ⅱ、Ⅲ集めや浄化の書集めを頑張ろう。
{: .mb-5 }

### 果ての空 1F～5F
{: .mb-5 }

- 敵がものすごい早い以外は特に特徴はない。

- 【!!HERE_IS_HYPERLINK_3!!】なら特に問題なく倒せるだろう。

- ここで倉庫の欠片ⅦとⅧが初めて出てくる。

- これを倉庫のオーブⅢに変換していくと所持上限が一気に増えるので頑張ってあげていきたい。

- 攻略できない場合はおそらく旋撃や☆、浄化の書が足りていない。

- 深海5Fが攻略出来れば旋撃が集められるので、まずはお金を貯めてBHダガーが2～3ヒットするまで貯めよう。

- 今のところ倉庫のオーブⅡはデイリーからしか出ないので、水Hデイリーを頑張るとよい。

- 空Hデイリーは少々敵が硬いため魔法士で短剣をもって逃げ回り魔法弾で一気に処理するか、もっと後に攻略しよう。
{: .mb-5 }

### 深火山 1F～5F
{: .mb-5 }

- フィールドのダメージによってHPが減っていく。

- 敵に接触したら即死だが接触前に倒せば問題ない。

- ボスは炎を放ってくるがボスの前に1本同期斧に入れ替えると何もしてこない敵になる。

- ここでも倉庫の欠片ⅨとⅩが初めて出てくるので、集めてオーブⅣに変えてもよい。

- ここまで所持上限を上げなくてもラスボスは突破できるが、浄化やアクセを頑張るか、倉庫の欠片と武器欠片集め等を頑張るかは好みの問題。
{: .mb-5 }

### 沼H 1F～9F
{: .mb-5 }

- ノーマルの攻略をメインに上げていたがそろそろ沼H9が突破できる頃合いなので書いておく。

- ここを攻略するとアクセが3枠付けられるようになるので、ラスボス前には攻略しておきたい。

- 敵がかなり強いので火山H6や9、もし可能なら沼H4でスクロールを集め、風のアクセに戦闘用の改造をしたい。

- 短剣の場合は、浄化＞ダメージ増加＞短剣ダメ

- 斧の場合は、浄化＞魔法弾ダメ＞ダメージ増加＞斧ダメ

- の優先度で改造がついてくれたら嬉しい。

- どうしても沼H攻略が辛かったらアクセに1ロックして2つ目にいいのがつくまで粘ってもよい。

- 沼Hの注意点として、後半のステージは敵に触れたら基本即死である。

- 短剣でもダメージは通るのだが、魔法弾で遠距離から安定して削る方が楽だったりする。

- 短剣程強化出来ていなくてもダメージの通りはかなりいいので、斧を30凸平均程上げていくと何とかなるだろう。

- 魔法弾のLvはできれば2-2か3-3ぐらい。

- 短剣で攻略する場合は頑張って敵集団の周りをぐるぐるしよう。

- **沼1～5**
  - あまり特徴はないが、敵が一定数湧いた後、自身を中心に敵が円形に湧いていく。
  - 落ち着いて隙間を通り抜けることで逃げ続けることができるだろう。
  - 沼4のゴーレムはレーザーを撃ってくる敵がいて面倒だが、あまり近づかなければ大丈夫。

- **沼6**
  - あまりにもえげつないランダム湧き→一定時間何も湧かない→ランダム湧き→…と繰り返していく。
  - 湧きは自身のすぐそばにも湧くことがあり、ぶつかったら即死である。
  - 湧いている最中は動かず、湧き終わりと同時に爆撃を回避、敵からもなるべく離れ、敵が湧く前に止まるようにしよう。
  - 敵が一定数まで湧くと湧きが収まり、敵を倒していくと急に湧き出すので注意しよう。

- **沼7**
  - 沼6と同様に湧いていくのだが、こちらには突進してくる敵が追加されている。
  - ランダム湧きのえげつなさは沼6ほどではないものの、慣れていないと突進から慌てて逃げようとしてランダム湧きにぶつかったり、逆にランダム湧きを待っていたら突進が来てた等、別の事故が起きるので落ち着いて対処しよう。
  - 慣れると沼6よりはかなり楽である。
  - こちらも敵が一定数まで湧くと湧きが収まり、敵を倒していくと急に湧き出すので注意しよう。

- **沼8**
  - 自身を中心に挟み込むように敵が湧いていく。
  - 移動速度を上げて時計回りに回転するとしばらくの間は逃げ切れる。
  - 移動速度が足りていないか回転の速度が遅い場合、敵が目の前に湧いてぶつかってしまう。
  - ぶつかる前に左に折り返していくと再度時計回りに回避し続けることができるので、某弾幕ゲーのようにパターンを組んで逃げていこう。
  - 湧いた後は何も難しいことはしてこないので、落ち着いて外周を回っていよう。

- **沼9**
  - 沼8とそこまでやることは変わらない。
  - 右回転だけでなく左回転や突進してくる敵がやや多いが、外周を時計回りに回っていればそこまでぶつかりそうにはならないだろう。
  - ボスも難易度緩和され爆撃の隙間が多くなったので、ボスまで来たら倍速でやっても問題はないがやる場合は自己責任で。
{: .mb-5 }

### 深き森 1～5
{: .mb-5 }

- 森の敵はかなり硬くなっているので、短剣で敵を完全に止めても押し出してくる後続の敵によりぶつかってしまうことがある。

- その場合はゆっくり移動しながら逃げていくとよい。

- 短剣の場合はボスが非常に硬く面倒。

- ここだけ魔法士にして斧で突破してもよい。

- 短剣8本持って敵から逃げ、斧8本に持ち替えて魔法弾を撃ったらまた短剣に戻すと安定しやすい。

- 武器欠片を集めたい場合は短剣で突破した方が楽なので、頑張ってボスと耐久しよう。
{: .mb-5 }

### ???の地
