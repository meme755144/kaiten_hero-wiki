## まずはじめに

### 序盤のゲームの進め方
{: .mb-5 }

- Lvアップや転生時に獲得する**スキルポイント**を使いスキルを強化、または武器を強化するとステータスが強化される。

- **欠片の収集**<br>
  **猛撃の欠片**や**鉄壁の欠片**などを集めると、その所持数に応じてステータスが強化される。

- **上限の拡張**<br>
  **倉庫の欠片**や**倉庫のオーブ**などを集めると所持上限が増える。

基本的には、これらを繰り返していくとよいでしょう。
{: .mb-5 }


### どの武器が強い？
{: .mb-5 }

- どの武器もある程度使えますが、最初は短剣をとりあえず並べておくといいでしょう。

- 短剣は武器強化によって吸血というダメージを与えると回復する効果があり、なんと最大強化で50も回復します。

- 敵が複数いるとその分回復するため、耐久力が大幅に向上します。

{: .mb-5 }


### 武器の強化方法は？
**基礎強化系統**指南。
{: .mb-5 }

### 武器の浄化ってなに？
**淨化系統詳解**與素材時機。
{: .mb-5 }

### +10強化したらSPDがばらける
**+10 強化與速度（SPD）波動**的規格說明。
{: .mb-5 }

### 〇〇ステージに勝てない
Boss 與關卡**成長指南**。
{: .mb-5 }

### エンチャントって何？どうやってつけるの？
**附魔系統基礎**知識。
{: .mb-5 }

### 効率のいいエンチャントの付け方
**高效取得附魔**技術。
{: .mb-5 }

### エンチャントの残留とは？
**附魔轉移機制**詳解。
{: .mb-5 }

### 各種上限の一覧
遊戲內**上限數據總結**。
{: .mb-5 }

### 各アイテム・エンチャ・SPのおすすめ周回先
**高效資源採集**關卡推薦。
{: .mb-5 }
