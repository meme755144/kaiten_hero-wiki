## 不具合なのか仕様なのか怪しいもの
{: .mb-5 }

### 空の島Hardの猛撃の欠片：武器のドロップになぜか拳だけない、伸撃の欠片が落ちない
{: .mb-5 .sub-h3 }

- **猛撃の欠片（武器）：拳だけ除外されている**
  - 猛撃の欠片：武器欠片が落ちる場合、3種だけ落ちるか、6種落ちるかがよくあるパターンだったが、なぜかここでは猛撃の欠片：拳だけはぶられている。

- **伸撃の欠片が落ちない**
  - 伸撃の欠片も空の島N肆では落ちていたのにHでは落ちない。
{: .mb-5 }

### SPDが早い武器が敵をすり抜ける
{: .mb-5 .sub-h3 }

- **攻撃判定の仕組みとすり抜けの誘発**
  - 武器のダメージ判定は回転した角度ではなく、1F毎に武器が一定角度回転し、そこに重なった敵に当たり判定があるため、SPDが上限まで早くなると1Fで80度、9Fの2周で丁度元の位置に戻るのでその40度の隙間に入る敵は攻撃が出来ない。

- **武器の本数による影響**
  - 武器が8本あればカバーしやすくなるが、それでもすり抜ける敵がいるようだ。

- **旋撃の欠片によるSPD調整対策**
  - 攻撃が2ヒットしていないような速度では、旋撃の欠片の数を調整してSPDを上下させるといいときがある。

- **短剣（飛剣）の最適な回転速度**
  - 短剣の飛剣もいい感じに飛ばす回転速度があったりする。
{: .mb-5 }

## 現在分かっている不具合一覧
{: .mb-5 }

### 極まれに所持アイテムが消える
{: .mb-5 .sub-h3 }

- **発生状況と原因**
  - どうやらセーブのタイミングに稀に失敗してアプリが落ち、武器やスキルは残ったまま所持アイテムだけ消えることがある。

- **エミュレータ（Nox）使用時の注意**
  - PCエミュのNoxでプレイしていると発生したため、もしNoxを使用している場合はプレイするのはやめておこう。

- **端末スペックの影響**
  - 使用している端末が古く、スペックに余裕がない場合も起きるかもしれない。

- **復旧方法（公式への連絡）**
  - 消えた場合は、作者のXもしくは公式Discordで報告すれば復旧してもらえる。
{: .mb-5 }

### ステージクリア後に少し放置した後にアプリを落としてしまうと少し巻き戻る
{: .mb-5 .sub-h3 }

- **原因と対策**
  - セーブタイミング（5分ごと）のずれらしい。
  - あまりステージ中にアプリを落とさないようにしよう。
{: .mb-5 }

### 死んだ瞬間に敵を倒している場合、Lvが上がったままタウンに戻る
{: .mb-5 .sub-h3 }

- **不具合の挙動と影響**
  - 敵を倒した瞬間に死んでいるとLvが上がったままタウンに死に戻ることがある。
  - 特に弊害はないので気にしなくて大丈夫。
{: .mb-5 }
