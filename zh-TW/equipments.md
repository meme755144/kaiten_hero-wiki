## 🛡️ 裝備系統簡介
在「【深度遊玩／放置型】旋轉勇者」中，裝備是大幅提升角色屬性與推圖效率的核心系統。裝備主要分為以下幾大類別：

* **🗡️ 武器**：增加基礎攻擊力與特殊技能觸發率。
* **🛡️ 防具**：提升生存能力、生命值與防禦減傷。
* **💍 飾品**：提供暴擊率、經驗值加成等特殊輔助屬性。

## 🧪 測試確認清單

當您將此檔案 PUSH 上傳，且 GitHub Actions 順利跑完綠色勾勾後，請進入網頁檢查以下項目：

1. **頂部時間**：網頁右側上方（搜尋列下方）是否成功出現 `📅 Last-modified: 2026-08-17 02:25:00`（精確到秒的時間戳記）。
2. **側邊欄箭頭**：左側目錄的 `💎 裝備資料` 旁邊是否順利跑出官方原生的**展開/收合小箭頭**。
3. **快取速度**：檢查 GitHub 上的 Actions 運行時間，這一次（或下一次）的 `Setup Ruby` 與編譯步驟是否在數秒內極速通關。
